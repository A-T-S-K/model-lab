# Canonical fixture format 1

`canonical.initial.json` is the input contract. `canonical.expected.json` is authentic output generated by the independent Python oracle and checked against the pinned original algorithm. See [reference provenance](../reference/PROVENANCE.md).

The initial file records the reference pin; configuration; document and shifted input/target IDs; parameter matrices; declared flattening order; Adam moments, hyperparameters, step and schedule; and deterministic continuation fields. Vocabulary contains ordinary characters only. `bosTokenId` denotes the extra output class. Matrices are rows of output features by input features. Flatten by `parameterOrder`, then matrix row, then column; all optimizer arrays use this order.

The expected file binds itself to the SHA-256 of the exact initial-state JSON. Its `positions` list follows input positions. Each position records token/position embedding, their sum, embedding RMSNorm, and `layers`. Each layer records pre-attention RMSNorm, Q/K/V, per-head causal scores/probabilities/weighted values, concatenated head output, projection/residual, pre-MLP RMSNorm, up/ReLU/down/residual. Position logits, probabilities, and target loss follow. Attention arrays contain only computed past/current cells; future cells are absent, never fabricated zeros.

`meanLoss` is the actual backward objective. `gradients` contains every parameter gradient in matrix shape. `adam` stores moments before/after, bias-corrected moments, effective learning rate, and the actual stored parameter difference (`after - before`). `postParameters` contains all updated matrices. `postUpdate` records a fresh run of the identical teacher-forced input through those matrices. It makes no sampled-string or improvement claim.

All canonical values preserve Python float precision. Display rounding belongs in the UI. Missing evidence has no numerical substitute. To change a fixture deliberately, edit/version its initial state, regenerate expected output with `reference/generate_fixture.py` in the documented canonical environment, and rerun numerical acceptance. Do not update expected numbers to conceal a runtime discrepancy.
