## Implementation and learner contract

PublicLessonSession still owns the sequence and decisions. The native training
execution and retained artifacts still own the numbers. The existing
`resolvePublicTrainingDepthContext` owns bound objective, contributions, completed
gradient, Adam and validated matched candidate comparison. Added presentation is a
read-only view, not another session machine, training implementation or numerical
trace. Shared code/source readers remain accessible.

The primary path explains purpose before technical names. Each beat gives a learner
question, short explanation, readable result and primary action; Values / Math /
Source stays visible. Error lists all five known targets, including END, and separates
selected p3 probability/position loss from observed whole-example mean objective.
Backward explains local dependency/sensitivity without reversed text, reversed
forward execution or already-changing parameters. One retained contribution shows
its actual before/contribution/after total; retained rows remain a subset. The
completed gradient comes directly from the finished native backward result, never
from summing that subset.

Adam's proposed before/after parameter is the readable result. Its moments,
correction, accepted schedule step, effective learning rate and actual proposed
value remain in optional depth. The exact runtime parameter index/name/row/column
witness is validated. All 896 declared canonical parameters receive proposals;
only one is displayed. Gradient is not the applied update, and gradient sign is not
a guarantee of finite improvement. The release-only world overlay labels the
proposal without overlapping optimizer fields; those inputs remain in Math.

The candidate comparison validates source snapshots/runs, input, targets, model,
architecture, numeric policy, session/generation and runtime. Accepted baseline and
provisional candidate probabilities bind the same p3/a occurrence. Separately
labeled whole-example mean losses are derived from all target probabilities.
No friendlier result is selected. Lower loss on this example establishes no general
improvement; unchanged and worse results remain valid.

Accept and Discard remain peer decisions, with pending acknowledgement separate
from authoritative outcome. Completion uses PublicLessonSession's actual successful
outcome; unavailable outcome makes no success claim. A bounded render-only receipt
view retains exact comparison evidence after resolution. It is labeled resolved,
with live scalar ancestry unavailable; it is not an active training transaction.
Accepted completion/Explore/workbench return restores the accepted computation;
discard restores the baseline. The next action is Explore or the existing workbench.

Four significant digits affect displayed summary text only. Stored values, comparison,
geometry and numeric policy are unchanged. Exact original binary64 numbers and
identities are directly available in expandable depth alongside existing equations
and source. Scientific notation preserves small nonzero values. Source now also
exposes the bundled native objective, backward and Adam mechanisms with file/symbol
and content revision. Optional check feedback explicitly grants no learning-validation
or comprehension evidence.
