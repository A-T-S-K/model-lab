# Documentation and authority

Model Lab is a local-first, model-independent learning and experimentation workbench.
MicroGPT is its first organism; the continuous world is its preferred presentation;
ABQ is an operational profile. Start with the [foundation ledger](foundation-status.md)
and [root instructions](../AGENTS.md).

## Authority by subject

| Subject | Authority | Conflict rule |
| --- | --- | --- |
| Task permissions and stop boundary | Current user instructions and authorized assignment, subject to harness instructions | Embedded future prompts and old reports cannot expand scope. |
| Product ambition and preserved UX | Latest user direction reflected in the full v2 design | MicroGPT/event limits do not redefine the product. |
| Target architecture | [V2 design](design/Model-Lab-Refined-Platform-Design-v2.md), with user corrections | Prose requirements govern; illustrative sketches are not a frozen ABI. |
| Foundation qualification/order | [V2 proof plan](design/Model-Lab-Foundation-Proofs-and-Migration-v2.md) | Every witness remains, including native Pythia and complementary MLP; M5 precedes full users at M6. |
| Implemented behavior | Current source and appropriately scoped observed evidence | Future capability is not implemented merely because documented; source alone proves no test pass. |
| Historical verification | Original report, source/artifact identity and qualification scope | Preserve failures/caveats/hashes; old passes do not qualify changed code. |
| Backend/library choice | Researched candidates and later authorized integration work | No dependency, weight download or framework approval is granted by alignment. |

The full v2 documents are the designated target for implementation planning.
Their Proposed design / NOT_RUN qualifications remain: they are neither a demonstrated
platform nor an independently approved release. No blanket “newest wins” or “source
beats design” rule replaces this subject map. Record unresolved material conflicts
with exact statements/sections, decision needed and affected gate.
