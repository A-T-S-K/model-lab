## Corrected visitor route

Open `/` → **TOUCH TO START** → **Why this prediction? · Explore** → **Spatial presentation · controlled learning** → **Predict**. The presentation switch uses the same accepted session and history without changing the URL or reloading. **Classic presentation** returns in place. `/?presentation=spatial` remains available directly.

For arithmetic, select Q or another Operation → **Inspect selected scalar**; follow its actual operands and source. For learning, **Step through learning** exposes guidance before advancement. **Continue** runs toward Ready. To inspect a partial contribution, Pause during backward and select **Continue to next contribution to pinned parameter**; alternatively, repeatedly select **Next step** until backward and then use the pinned control. Continue subsequently reaches **Candidate ready — not accepted**. Inspect current/candidate/shared scales, then explicitly Accept or Discard. For ablation, select **Weighted values**, Head 1, **Test without this head**, inspect downstream operations and both arms, then **Return to current model**.
